# Shelf Discovery Lab

The imported Shelf app now runs as a Replit pnpm workspace, with its original design and library-discovery flows.

Start the `artifacts/shelf: web` and `artifacts/api-server: API Server` managed workflows and open Preview.

See [replit.md](replit.md) for configuration, tests, temporary-state behavior, and the optional private reviewer gate. The original imported project and its documentation remain in `.migration-backup/`.

This is a demonstration catalog: all records and availability counts are synthetic, with no live holds or patron accounts.
